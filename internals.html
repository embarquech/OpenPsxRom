Boot sequence

  1. The BIOS calls the pre-boot entry ([1F000080h]) before the kernel is ready.

  2. Switch OFF: bypass, or tail-jump to the bank 2/3 firmware (checked). Switch ON: OpenPsxRom installs a COP0 execution breakpoint on the shell entry (80030000h) with the debug vector (80000040h) pointing to its hook, and returns.

  3. When the kernel reaches the shell, the breakpoint fires: the hook copies the unpacker to RAM, unpacks the OMC1 payload to 801A0000h and starts the menu there.

  4. Booting a disc: SYSTEM.CNF, SetConf, resident core if needed, the executable started through a small trampoline that clears its BSS.

Resident core

Kept small (3 KB, in unused kernel space): it registers a handler in the kernel’s exception chain (SysEnqIntRP priority 0) called on every exception and interrupt: video mode forcing, cheats, Xplorer switch (off then on opens the in-game menu), serial bytes passed to the ROM handler, and break exceptions (PCDRV, debug halt) handled before the BIOS. It also hooks the BIOS putchar (TTY) and the unresolved-exception handler (crash screen). Everything big runs from the cartridge ROM (src/romx.c), which has no writable data: its state lives in the shared block.

Flash driver

Commands go through KSEG1 (BF000000h, uncached). The chip is identified with the JEDEC ID sequence (and the Atmel/SST alternative), with a 10 ms pause for Atmel chips. Page chips are written 128 or 256 bytes at a time after the unlock sequence (which also enables software data protection), sector chips are erased then programmed byte by byte with DQ7 polling. Identical pages are skipped, every block is read back and retried. On double-chip carts the commands for 40000h-5FFFFh go to the second chip. The EXP1 bus timings set by the BIOS are kept (longer ones make the Xplorer drop off the bus).
